## 📖 About

**GIFT (DAHEJ) CALCULATOR** is a command-line Python application designed as a satirical social-awareness project.

The program interacts with the user through a series of menu-driven questions and gathers information in a structured profile. At the end, regardless of the responses, it reminds users that **dowry is illegal, unethical, and unacceptable.**

The application is inspired by the interface of a restaurant billing system but is intended solely as a humorous awareness initiative. :contentReference[oaicite:1]{index=1}
